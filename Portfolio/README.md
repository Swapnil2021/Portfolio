# Portfolio Website (React.js with Vite)

This is a personal portfolio website built using React.js with Vite. It showcases projects, skills, experience, and contact information.

## Features
- **Fully Responsive:** Works on all devices.
- **React Router:** Enables navigation between pages.
- **Reusable Components:** Organized structure for easy maintenance.
- **Dark/Light Mode:** Optional theme switching.
- **Animations:** Smooth transitions using Framer Motion or CSS.
- **Contact Form:** Integrated with email service.

## Technologies Used
- React.js
- Vite
- React Router
- Tailwind CSS / Styled Components
- Framer Motion (for animations)
- Email.js (for contact form handling)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
